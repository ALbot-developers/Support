# About
Albot公式サポートサーバー用プログラム

# Command
| コマンド | 引数 | 説明 |
| ---- | ---- | ---- |
| /ping | なし | BOTのテスト用のpingコマンド|
| /setup | channel<Discord.channel> | サポートチケットの開始チャンネルを指定し、チケットシステムのセットアップを行う。 |

# Ticket Flow
サポートチケットは以下の流れで動作する

1. 顧客によって開始ボタンが押される
2. ドロップダウンメニューを含むEphemeral Messageにより、顧客自身が問い合わせの種類を次の一覧から選択する

- 「その他の質問」
- 「サブスクリプションを伴わない不具合のご報告(BOT)」
- 「サブスクリプションを伴わない不具合のご報告(Webサイト)」
- 「サブスクリプションに関する問い合わせ」

3. Ephemeral Messageを編集して、よくある質問への誘導メッセージの追加と「サポートチケットを開始する」ボタンを有効化する
4. 顧客がサポートチケットを作成すると、.envの「OPEN_TICKET_CATEGORY_ID」のIDのカテゴリへ専用チャンネルを作成し、Ephemeral Messageを更に送信して専用チャンネルへ誘導
5. 専用チャンネルの作成後、質問の概要を促すメッセージを自動送信
6. (人力の普通のサポート対応)
7. サポートメンバーがサポート終了を設定
8. .envの「CLOSED_TICKET_CATEGORY_NAME」に当てはまるカテゴリのうち、チャンネル数が50件未満かつ$nが最も小さいカテゴリを検索し、チャンネル名やトピックの編集をする。
9. 手順8で検索したカテゴリーに当該専用チャンネルを移動する。
